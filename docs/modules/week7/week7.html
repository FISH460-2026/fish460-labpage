Data Visualization Workflow Checklist

Important

Only do the download software steps IF YOU DO NOT ALREADY HAVE R and RStudio on your laptop!

1. Download Required Software

Install R

    • Windows
    • MacOS
    • Linux

Install RStudio

2. Open RStudio and Create an RStudio Project

    • File → New Project
    • Existing Directory OR New Directory

Using an RStudio Project helps keep file paths organized and reproducible.

3. Download and Organize Data Files

Example project structure:

my-data-project/
├── data/
├── figures/
├── code/
└── README.md
Important

You cannot drag and drop files from your computer into RStudio. You need to use the file explorer on your computer to move files into the correct folder in your project directory! Once files are in the correct folder, you can use RStudio’s file pane to navigate to the file and click on it to open it and edit it in RStudio.

4. Open an .Rmd or .qmd file & Install Required Packages

In your files view pane, navigate to the code/ folder and open a new .Rmd or .qmd file by clicking the New File dropdown

Install tidyverse

Load tidyverse

Note

You can insert a code chunk into a .Rmd or .qmd file with the hotkey Ctrl + Alt + I (Windows) or Cmd + Option + I (MacOS).

5. Load Data into R

Read CSV files

Example:

library(tidyverse)

my_data <- read_csv("data/my_data.csv")
Note

Pay attention to file paths! The path is relative to the location of your .Rmd or .qmd file. If your data file is in a different folder, you need to include the folder name in the path (e.g., data/my_file.csv mean that the file is in the data/ folder and your code file is in the code folder which is at the same level as the data folder).

my-data-project/
├── data/my_data.csv
├── figures/
├── code/draft_figure.qmd
└── README.md

Check the imported data

head(my_data)
colnames(my_data)
glimpse(my_data)

6. Reshape Data for Plotting

Many plotting workflows work best with long-format data.

Convert wide data to long format

Example

long_data <- my_data %>%
  pivot_longer(
    cols = starts_with("Sample"),
    names_to = "sample",
    values_to = "value"
  )

Verify reshaped data

head(long_data)
    • One observation per row
    • Grouping variables separated into columns
    • Measurement values stored in a single column

7. Make Initial Figures with ggplot2

Basic scatterplot

ggplot(long_data, aes(x = sample, y = value)) +
  geom_point()

Basic boxplot

ggplot(long_data, aes(x = sample, y = value)) +
  geom_boxplot()

Add labels and themes

ggplot(long_data, aes(x = sample, y = value)) +
  geom_boxplot(fill = "skyblue") +
  labs(
    title = "Initial Data Visualization",
    x = "Sample",
    y = "Value"
  ) +
  theme_minimal()

Save figures

ggsave(
  "figures/initial_plot.png",
  width = 6,
  height = 4
)

# Data Visualization Workflow Checklist

::: callout-important
Only do the download software steps IF YOU DO NOT ALREADY HAVE R and RStudio on your laptop!
:::

## 1. Download Required Software

### Install R

-   [ ] Go to the <https://cran.r-project.org/>
-   [ ] Download the version for your operating system:
    -   Windows
    -   MacOS
    -   Linux
-   [ ] Run the installer and follow the default installation steps

### Install RStudio

-   [ ] Go to <https://posit.co/download/rstudio-desktop/>
-   [ ] Download the free version of RStudio Desktop
-   [ ] Install RStudio after R is already installed

## 2. Open RStudio and Create an RStudio Project

-   [ ] In RStudio:
    -   File → New Project
    -   Existing Directory OR New Directory
-   [ ] Select your project folder (or create a new one)

Using an RStudio Project helps keep file paths organized and reproducible.

## 3. Download and Organize Data Files

-   [ ] Download your data files as `.csv` !
-   [ ] Create folders in your project to keep things organized

Example project structure:

``` text
my-data-project/
├── data/
├── figures/
├── code/
└── README.md
```

-   [ ] Place all CSV files into the `data/` folder

::: callout-important
You cannot drag and drop files from your computer into RStudio. You need to use the file explorer on your computer to move files into the correct folder in your project directory! Once files are in the correct folder, you can use RStudio's file pane to navigate to the file and click on it to open it and edit it in RStudio.
:::

## 4. Open an .Rmd or .qmd file & Install Required Packages 

In your files view pane, navigate to the code/ folder and open a new .Rmd or .qmd file by clicking the `New File` dropdown

### Install tidyverse

-   [ ] In the Console, run `install.packages("tidyverse")` 

### Load tidyverse
-   [ ] After installation finishes, load the package by inserting a code chunk and running `library(tidyverse)`

::: callout-note
You can insert a code chunk into a .Rmd or .qmd file with the hotkey `Ctrl + Alt + I` (Windows) or `Cmd + Option + I` (MacOS).
:::


## 5. Load Data into R

### Read CSV files

-   [ ] Use `read_csv()` from tidyverse to import data! This is IMPORTANT because it makes your data import process reproducible and allows you to easily share your code with others. If you just open the CSV file in Excel and copy-paste it into R, that is not a reproducible workflow and it will be impossible for others to get your data into R if they are running a copy of your code.

Example:

``` r
library(tidyverse)

my_data <- read_csv("data/my_data.csv")
```

::: callout-note
Pay attention to file paths! The path is relative to the location of your .Rmd or .qmd file. If your data file is in a different folder, you need to include the folder name in the path (e.g., `data/my_file.csv` mean that the file is in the `data/` folder and your code file is in the code folder which is at the same level as the data folder).

```text
my-data-project/
├── data/my_data.csv
├── figures/
├── code/draft_figure.qmd
└── README.md
```

:::

### Check the imported data

-   [ ] View the first few rows

``` r
head(my_data)
```

-   [ ] Check column names

``` r
colnames(my_data)
```

-   [ ] Check the data structure

``` r
glimpse(my_data)
```


## 6. Reshape Data for Plotting

Many plotting workflows work best with **long-format** data.

### Convert wide data to long format

-   [ ] Use `pivot_longer()`

Example

``` r
long_data <- my_data %>%
  pivot_longer(
    cols = starts_with("Sample"),
    names_to = "sample",
    values_to = "value"
  )
```

### Verify reshaped data

-   [ ] Inspect the new table:

``` r
head(long_data)
```

-   [ ] Confirm
    -   One observation per row
    -   Grouping variables separated into columns
    -   Measurement values stored in a single column
